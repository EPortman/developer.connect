# Name Registry API

---

## Overview

The Names Registry is a centralised, electronic register of business names and their statuses for various legal entity types operating in the Province of BC. The Namex API provides a real-time, secure, direct link between your business systems and the Names Registry.

With this API you can submit the following transactions:

 - Create and submit Name Requests
 - Check the availability of a business name
 - Validate a name against naming rules based on legal type
 - Retrieve the status of an existing Name Request

To set your session API key, click on the top, right AUTHORIZE button and under API Key Auth enter your key value. Click on AUTHORIZE, then OK.
